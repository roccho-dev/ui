# Scope to meta issue template

Use this template before implementation starts for every non-trivial PR.

## Practical scope

State the exact repo work.

## Direct purpose

State the immediate outcome.

## Upper purpose

State the larger repo or product goal.

## Meta purpose

State the future review cost or drift risk this reduces.

## Highest objective

High-value company build and eventual sale.

## Completion criteria

List observable facts that must be true before the issue can close.

## Non-scope

List what must not be changed.

## Merge-blocking conditions

List facts that block merge or closure.

## Tests to keep

List current-fact tests that protect the surviving contract.

## Tests not to keep

List tests that do not protect current behavior.
