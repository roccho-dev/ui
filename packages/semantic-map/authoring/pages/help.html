Semantic Map / Help

図を変更するための全契約

正本は承認済み変更を1行ずつ足すDecisionLogです。StateはLogを決定的にreduceした現在値、Proposalは未承認候補、SceneとmaxGraphは表示です。

共有とSource

共有URLの運搬路は外側の汎用#dataだけです。中身はEnvelope/3で、DecisionLog・Proposal・Viewを保持します。Semantic MapはURL codecやpublish先を所有しません。

AcceptはProposalを検査してDecisionLogへ1件だけappendします。RejectはDecisionLogを変えません。共有URLは確定済みEnvelopeから後段でprojectします。

Sourceから承認済みState JSONL、DecisionLog JSONL、Envelope JSONを取得できます。元の空白やキー順ではなく、同じ意味のcanonical出力です。

Pattern

1 Scene＝1 Patternです。map/1は位置、graph/1は接続、seq/1は時間、chart/1は棒・折れ線・円・ドーナツ・散布・heatmap・sunburstを表します。同じStateを再投影し、Viewだけを変えます。

resource

GeoSpecとPolicyはdomain意味を保ちます。子mapの名前空間は@mount/です。埋め込みstateは親runtimeからtyped messageで渡し、URL契約を増やしません。

編集と承認

GUI操作はLocal Draftへ積みます。Reviewで差分を確認し、Acceptで初めてDecisionLogを変更します。Local DraftのRejectは通信せず承認済みStateへ戻します。

境界

secret、旧#doc・#apply、shortener、bundled backend、認証、DB、自動mergeはありません。URL上限8,192文字、Scene上限2,048要素を超えたらfail-closedです。

YAGNI: 未要求を作らない。KISS: 1 Log、1 Envelope、1 URL field。DRY: URL codecは汎用層だけ。SOLID: Domain、Pattern、Protocol、Projection、Renderer、Appを分ける。
