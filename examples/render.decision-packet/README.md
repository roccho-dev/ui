# `render.decision-packet@1` example

This example proves one public, non-authoritative `decision-packet/1` through the existing semantic-map implementation.

```text
input/decision-packet.json
+ input/invocation.json
→ packages/decision-packet
→ packages/semantic-map
→ apps/artifact-shell/capabilities/render-decision-packet
→ dist/index.html
+ dist/agent.json
+ dist/receipt.json
```

The Packet is the shared human/agent meaning. The generated interactive HTML is a reviewable example, not accepted state or production publication.
